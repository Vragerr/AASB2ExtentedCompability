# AASB2 Extended Compatibility

Build and manage a multi-floor colony in RimWorld with compatibility fixes and vertical building options for **As Above, So Below 2**.
# DISCLAIMER 
Mod created by using ai.
- **Glass floors and skylights.** See the terrain, pawns, objects and colored light on the floor below. A separate gameplay lighting option lets daylight reach plants through glass. Dubs Skylights is supported when installed. With Adaptive Storage Framework, storage displays use the container’s original item placement.
- **Vertical ventilation.** An openable grate exchanges heat between rooms on neighboring above-ground floors without using power.
- **Pipes and cargo between floors.** Vertical risers reserve their pipe connections and link compatible Dubs and Rimefeller networks. Factory vertical cargo ports transfer items between floors when Vanilla Furniture Expanded - Factory is installed.
- **Anima tree settings.** With Royalty, limit natural spawns to 1–50 per map or keep natural spawns on the main floor.
- **Skipdoors.** Eligible pawns can use Skipdoors for movement and work between floors. The adapter follows Skiptech's access rules. Multi-stage work includes hauling and rescue. Mounted travel follows both the rider’s and the mount’s Skiptech permissions. Roped groups use the native routes.
- **Experimental exterior views.** The unfinished Endless Horizon adaptation is off by default. When Endless Horizon is installed, the Development (DEV) tab offers an opt-in and a separate upper-floor option. Changing the main adaptation requires a restart.

## Gameplay status

- **Owner-tested in game.** Cold and hot water, Dubs heating and Rimefeller risers on an existing colony and a test save. Campfire flames, blood, filth, pollution, items and colored light have been seen through glass. Ordinary colonists and cargo drones have been observed hauling through Skipdoors.
- **Awaiting in-game verification.** Winter ground and snow, furniture overlaps and visible pipes through glass or OpenAir. Mixed stair and Skipdoor routes, including a save during the stair approach. Direct inter-floor Skipdoors with Giddy-up mounts.
- **Known limits.** Mounted stair travel uses the original mods. Mixed stair and Skipdoor routes are currently for unmounted pawns. The glass projection does not copy the map-wide Fleck batch used for some smoke and sparks. UI overlays remain on the active floor.
- **Experimental.** The Endless Horizon adaptation is frozen and stays off by default.

## Dependencies and installation

Requires RimWorld 1.7, [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and [As Above, So Below 2](https://steamcommunity.com/sharedfiles/filedetails/?id=3776015553). Optional mods activate only their own compatible adapters. These include Dubs Bad Hygiene, Dubs Central Heating, Rimefeller, Adaptive Storage Framework, and the following: [MigCorp - Skiptech](https://steamcommunity.com/sharedfiles/filedetails/?id=3626074566), [Endless Horizon](https://steamcommunity.com/sharedfiles/filedetails/?id=3842486043), [Giddy-Up 2 - Continued](https://steamcommunity.com/sharedfiles/filedetails/?id=3674332861), [Dubs Skylights](https://steamcommunity.com/sharedfiles/filedetails/?id=833899765), [Vanilla Furniture Expanded - Factory](https://steamcommunity.com/sharedfiles/filedetails/?id=3686924415).

Extract the ZIP into RimWorld's `Mods` folder. Keep the archive's folder name `mod` so the game can find existing local settings. Enable it after Harmony, AASB2 and the optional mods you use. Avoid installing a second copy with the same package ID.

Mod Settings explains missing or incompatible optional dependencies. The glass view and gameplay lighting are independent. An update preserves existing buildings and settings. First-time installation on an existing save can initialize Dubs Bad Hygiene risers through native pipe updates. Back up your save before removing the mod or changing dependencies.

## Reporting issues

Use Mod Settings → AASB2 Extended Compatibility → Diagnostics. The general compatibility report is available from the main menu. Open a colony map for map-specific reports and select a pawn or building for its report. Reports are written under `Diagnostics/AASB2Extended/` in the RimWorld user data folder. In a bug report, include the floors, related mods, versions, steps and relevant report excerpts. Review them for personal data first.
